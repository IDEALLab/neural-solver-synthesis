# Documentation

Start with the following release documents:

1. `EVIDENCE_MAP.md` maps each scientific claim to a compact result file.
2. `final_evidence_index.json` records machine-readable metrics and checksums.
3. `REPRODUCTION.md` separates local checks from artifact-backed regeneration.
4. `release_manifest.md` defines the released code and evidence surface.
5. `release_artifact_inventory.json` inventories datasets, checkpoints, and
   checked-in bundles.
6. `LICENSING.md` records the applicable reuse boundaries.

Portable helper documentation is under `../scripts/README.md`.
