# Licensing

This publication snapshot does not add a blanket license for the original code
at the repository root. Unless a file or directory states otherwise, reuse of
that code requires permission from the copyright holders.

Vendored dependency trees retain their own notices and licenses. In particular,
consult the license files under `deps/open-r1`, `deps/ShinkaEvolve`, and
`deps/bigcode-evaluation-harness` before reusing those components. The absence
of a license file in another dependency tree does not grant reuse rights.

Models and datasets hosted outside Git are governed by the license and source
terms recorded on their individual artifact cards. Standard benchmark instances
are referenced by source URL and checksum when redistribution rights are not
established.
